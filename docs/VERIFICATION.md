# Проверка SYSCORE, 05.10.2026

Этот отчёт заменяет проверку 04.10.2026: открытая публикация документов основателя отменена по новому запросу владельца.

## Выполнено

- Зависимости и lockfile не менялись; для нового визуала не добавлялись библиотеки, WebGL или canvas.
- `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` успешны. Production standalone server действительно запущен.
- Unit: strict validation / sanitization, limiter / captcha / hostname, URL fallback, контраст; квалификации только как metadata; запрет legacy URL и image optimizer; согласованность шести узлов и четырёх шагов планируемой сети.
- Smoke: девять страниц, sitemap / robots, health / 404, CSP nonce и security headers, OG PNG, Origin / JSON / body limit / consent / honeypot, закрытый приём обращений и scanner. Реальных отправок нет.
- Privacy smoke: все 11 прежних PDF и 11 WebP возвращают410, no-store / noindex; проверены HEAD и encoded image optimizer URL. Brand PNG продолжает возвращать200. На главной / странице основателя нет ссылок или изображений сканов.
- Исходные 11 документов владельца в Downloads не удалены и не изменены. Из текущего дерева репозитория удалены только публичные копии, превью и инструменты их массовой публикации.
- Browser: 63 комбинации (9 страниц × 360,390,768,1024,1440,1920,2560px): один H1, нет horizontal overflow или broken images. Console error/warn не обнаружены.
- Вручную: mobile menu, Esc / возврат фокуса, клавиатурное переключение PhD-фильтра без скана, OSINT с новым описанием и CTA, выбор NGFW, четыре шага сценария / reset, Cisco / Fortinet / MikroTik с изменением содержания и официальной ссылки. После финального build отдельно перепроверены подписи «Следующий шаг».
- Motion: RAF курсора останавливается в покое / скрытой вкладке; ядро приостанавливается вне viewport; SVG-щит вместо универсального «Открыть»; убран animated blur заголовка и animated clip-path Liquid-перехода. Reduced motion и coarse pointer сохраняют нативное поведение.
- Исходный бизнес-план прочитан целиком; в сайт перенесена только концепция будущего изолированного учебного контура. PDF, коммерческие суммы, закупки и прогнозы не опубликованы.
- Предыдущий audit04.10: production0 / dev5high. Это историческое измерение, не новый audit. Зависимости с тех пор не менялись; несовместимый downgrade не применялся.

## Производительность

Lighthouse13.5 использовался для локального production server. Десктоп страницы киберполигона:98 /100 /100 /100, CLS0. Mobile страницы:92 /100 /100 /100, CLS0. Эти два замера сделаны до финальной замены Liquid clip-path на transform / opacity.

Замеры главной на этой машине были нестабильны (Performance52–91); один запуск дал CLS0.311, следующие CLS0. Финальный замер после оптимизации Liquid:68 /100 /100 /100, CLS0, FCP1.0s, LCP4.0s, TBT810ms; non-composited animations0. Мобильная загрузка имеет резерв для дальнейшей оптимизации. Наблюдалась дополнительная нагрузка Windows Defender. Это не доказательство, что вся разница вызвана антивирусом; нельзя обещать97 или постоянные60fps на основании выборочного запуска. Живой production smoke фиксируется в отдельном release handoff после публикации.

## Границы проверки

Внешняя доставка, Redis и Turnstile в live-mode не подключены. Unit-тесты сервиса используют локальные mock-ответы, а не отправку настоящих обращений. Нельзя заявлять готовность live-form до настройки secrets / endpoint и юридического утверждения. Телефон / WhatsApp — обычные подтверждённые ссылки; тестовый звонок/сообщение не отправлялись.

Киберполигон — интерактивная концепция, не работающий EVE-NG control plane: нет VM, реальных атак, экзаменов или подключения университетских серверов. Программы планируются, партнёрства с вендорами не заявляются. Все действия схемы локальны в браузере.

Обычное удаление файлов из main НЕ удаляет их из истории GitHub, старых deployment URL, браузерных / поисковых кешей и уже скачанных копий. Force-push и удаление старых Vercel deployments не выполнялись: требуется отдельное подтверждение владельца. Защита410 относится к новой версии сайта, а не к старым неизменяемым деплоям.

Физический TV / пульт, screen-reader и длительный нагрузочный/пенетрационный тест не проводились. Lighthouse Accessibility100 не является сертификатом полной WCAG AA. EN / KZ отсутствуют сознательно, без фиктивного переключателя.
