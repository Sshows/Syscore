# Syscore

Презентационный сайт центра кибербезопасности Syscore (System Security Core). Стек: Next.js (App Router), TypeScript, Tailwind CSS. Хостинг: Vercel.

Проект готовится к запуску. На сайте нет реальных контактов, БИН, отзывов, статистики и заявлений об официальном партнёрстве.

## Локальный запуск

Нужны Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Сборка и продакшен-проверка

```bash
npm run build
npm run start
```

Прочие команды:

```bash
npm run lint
npm run format
```

## Деплой на Vercel

1. Импортируйте репозиторий `Sshows/Syscore` в Vercel.
2. Framework Preset: Next.js, команда сборки `npm run build`.
3. В Environment Variables задайте `NEXT_PUBLIC_SITE_URL` (канонический URL продакшена, без завершающего слэша).
4. После деплоя проверьте `/`, `/privacy`, `/personal-data`, `/sitemap.xml`, `/robots.txt`.

## Где менять контент

Весь текстовый контент сайта — в `content/site-content.ts`. Не дублируйте формулировки в JSX.

## Где менять цвета и шрифт

- Цвета и семейство шрифта: `tailwind.config.mjs` и `app/globals.css`
- Подключение Manrope: `app/layout.tsx` (`next/font/google`)

Акцент: мятный `#3ED6A8`. Текст: графитовый `#1E2328`. Фон: белый.

## Структура

```
app/                 маршруты, SEO, OG-изображение
components/layout/   шапка и подвал
components/sections/ блоки главной
components/ui/       кнопки, бейджи, появление блоков
content/             тексты сайта
```

## Что нельзя публиковать без заказчика

- телефон, email, адрес, БИН и любые «похожие на настоящие» заглушки;
- логотипы и названия организаций как действующих партнёров;
- слово «партнёр» / «официальный партнёр» применительно к МУИТ;
- отзывы, сертификаты, награды, счётчики клиентов;
- юридические политики как утверждённый документ — текущие страницы `/privacy` и `/personal-data` это структурные черновики, их должен согласовать юрист до запуска;
- включённую форму обратной связи, пока нет реального канала приёма данных.

## Безопасность

- `.env*` в `.gitignore`, в репозитории только `.env.example`;
- security headers заданы в `next.config.ts`;
- форма на главной задизейблена и не отправляет данные.
